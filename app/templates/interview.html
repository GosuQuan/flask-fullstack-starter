Flask + 数据库 · 面试速览

完整版见仓库 docs/interview-flask-db.md。下面摘几道与本项目代码直接相关的问答。

Q: 为什么用 create_app 工厂而不是全局 app？

工厂便于测试（多次建 app、换配置）、延迟加载扩展，也方便挂多个 Blueprint。见 app/__init__.py。

Q: SQLAlchemy ORM 相对手写 SQL 的取舍？

ORM 提升生产力、防注入（参数绑定）、跨库方言；复杂报表/窗口函数有时仍用手写 SQL 或 Core。本项目用 ORM 的 User 模型 + db.session。

Q: 密码为什么存 hash 而不是明文？

库被拖库时明文直接泄露。本项目用 Werkzeug generate_password_hash / check_password_hash（见 app/models/user.py）。

Q: Flask-Login 的 session 里存了什么？

通常只存 user id（通过 user_loader 回查）。cookie 签名依赖 SECRET_KEY。见 login_user 与 load_user。

Q: db.create_all 和迁移（Alembic）差在哪？

create_all 只建缺失表，不改已有列；生产应用 Flask-Migrate/Alembic 做可版本化 schema 变更。本脚手架为演示在启动时 create_all。

Q: 为什么选 PostgreSQL 而不是 SQLite？

并发写、类型/约束、连接池、与生产环境一致。SQLite 适合单机原型。本项目强制 Postgres，见 DATABASE_URL / README。
